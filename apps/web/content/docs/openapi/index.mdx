[Download the OpenAPI schema](/openapi.json) to import Momento into your API client or generate a client library. The API also exposes its current schema at [`/api/openapi.json`](https://momento.mthatguy.workers.dev/api/openapi.json).

The playground sends requests to the public Momento API. Stamping creates a real signed receipt. No API key is required.

For a guided walkthrough, receipt formats, and offline verification, see the [API guide](/docs/api).
